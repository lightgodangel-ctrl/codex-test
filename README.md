# 오늘의 할 일

브라우저에서 바로 사용할 수 있는 반응형 할 일 목록 웹앱입니다. 할 일을 추가하고, 완료 상태로 바꾸거나 삭제할 수 있으며 모든 내용은 브라우저의 `localStorage`에 자동 저장됩니다.

## 실행 방법

별도의 설치나 빌드 과정이 필요하지 않습니다.

1. 저장소를 내려받습니다.
2. `index.html`을 브라우저에서 엽니다.

로컬 웹 서버를 사용하려면 저장소 루트에서 다음 명령을 실행한 뒤 `http://localhost:8000`에 접속하세요.

```bash
python3 -m http.server 8000
```

## 주요 기능

- 입력창 또는 Enter 키로 새 할 일 추가
- 체크박스로 완료 여부 변경
- 개별 할 일 삭제
- 전체 / 진행 중 / 완료 항목 필터링
- 브라우저 저장소에 목록 자동 저장
- 모바일과 데스크톱에 대응하는 반응형 UI

## 파일 구성

- `index.html`: 앱의 화면 구조
- `style.css`: 반응형 레이아웃과 디자인
- `app.js`: 할 일 관리 및 브라우저 저장 로직
